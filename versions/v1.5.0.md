# 1.5.0 — 提示浮层移到上方，危险按钮单独隔开

**一句话**：节点「作用」的完整提示不再压在鼠标下面（改成节点上方的浮层），删除类按钮挪到最右、常态红色，和常用按钮隔开。

## 说明

1. **节点作用提示**：原来是浏览器原生 tooltip（跟着鼠标、常在下方，正好被指针盖住），改成节点正上方的浮层，`pointer-events: none` 永不挡操作，最多两行截断照样能看全文。
2. **节点卡片底部**：常用按钮（打开、发送数据）留在左边，删除 `×` 推到最右，前面加一条竖分隔线，常态就是红色边框红字，不再只在悬停时变色。
3. **主题条**：`＋新建主题`、`改名` 在左；`删除主题` 推到最右，常态红色，二次确认时整块填红（`danger-armed`），误点一目了然。
4. 悬停节点作用也能用键盘聚焦（`tabIndex`），提示同样出现。

## 验证

- Host 测试 36 项全过；渲染冒烟 7 项全过（含「主题条渲染创建/改名/删除控件」）。
- 真实界面未验：重启后把鼠标放在节点作用上，看浮层是否在节点上方。
